# Pixel Peeper
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Designers learning from desktop websites, confirmed through the requested clickable prototype and detailed flow specification.

## Product Purpose
Turn live webpages into design lessons by combining computed styles and a captured selection with evidence-based interpretation. Let users compare two or three references, choose what to borrow, and export a design direction.

## Positioning
Inspect Element for design language. Every claim distinguishes directly measured facts from interpretation.

## Operating Context
Browser extension used over the original website. Floating interaction preserves the website viewport. Users select, explicitly analyze, read, save, compare, export, and repeat.

## Capabilities and Constraints
Measured values, deterministic rules, inferred lessons, element/page scopes, library, comparison, DESIGN.md, tokens.json, and CSS exports. AI transmission occurs on Analyze, not on hover. Threshold checks require applicability; unavailable values must remain unavailable. Prototype is illustrative: it reads the local demo page and simulates model output.

## Brand Commitments
Pixel Peeper is provisional. Minimal, clean UI inspired by the supplied Granola screenshots; vibrant accents and the supplied detective illustration as a peeping corner launcher with a playful saved-idea pose. No side panel that reduces website width.

## Evidence on Hand
Four user-supplied reference images and an existing static prototype in docs/prototype/index.html. No live model integration or validated user research supplied.

## Product Principles
- Preserve website geometry while inspecting.
- Separate evidence from interpretation per claim.
- Explicit capture and analysis before transmission.
- Teach a useful lesson before presenting exhaustive facts.
- Preserve references and provenance through export.

## Open Decisions
Production model, authentication, cloud storage, rules library, supported browsers, and final name.
